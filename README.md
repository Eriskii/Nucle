# Nucle

A daily nuclear strike planning puzzle, played on a 1960s air defense console. Everyone
gets the same map, warheads, weather and objective each day. There's no backend: the
puzzle is generated from the date, and scores live in a cookie.

```sh
npm install
npm run dev
npm test                  # add NUCLE_DAYS=365 to audit a full year of puzzles
npm run build             # static site in build/
```

Or with Nix, which supplies Node for you:

```sh
nix develop               # shell with Node, then use the npm commands above
nix build                 # static site in result/
nix run                   # serve it on http://localhost:4173, or nix run . -- 8080
nix flake check           # run the tests
```

`?day=N` opens any puzzle number, unscored.

## How puzzles work

`src/lib/game/generator.ts` rolls a theatre, arsenal, weather, objective and conditions
from the day number, then a solver plays it. The solver's result sets the goal and par,
and proves the puzzle can be solved using only settings the console's controls can
produce. Rolls it can't solve are rerolled. `difficulty.ts` scores each puzzle by simulating
plausible but unoptimized players.

The daily board is simulated from the solver's par, since there's no server to hold real scores.

## How it's calculated

[docs/CALCULATIONS.md](docs/CALCULATIONS.md) walks through everything from date to score. [docs/EFFECTS.md](docs/EFFECTS.md) has the weapon effects sources and how far the model sits from published figures. After each strike, the in-game "Learn what you've done" report shows the same workings for your own plan.

## Data

`static/data/weather-*.json` is real historical weather from [Open-Meteo](https://open-meteo.com/) (CC BY 4.0), ERA5 reanalysis from the Copernicus Climate Change Service, built by `npm run weather`.

The rest of `static/data` is generated by `npm run data -- <source dir>`. The source dir needs:

- `pop/` and `built/`: [GHS-POP and GHS-BUILT-S R2023A](https://ghsl.jrc.ec.europa.eu/) at 30 arcseconds (European Commission JRC, CC BY 4.0)
- `places` (the simple edition), `places-full` (the full edition, for Russian names), `lakes`, `rivers`, `roads`, `rail`, `urban` and `admin` as `.geojson`: [Natural Earth](https://www.naturalearthdata.com/) 10m (public domain)

Streets and buildings stream at runtime as vector tiles from [OpenFreeMap](https://openfreemap.org),
using the [OpenMapTiles](https://www.openmaptiles.org/) schema, with data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors.
They're for display only. Scoring uses the population and built-up rasters.

Fonts: Routed Gothic and Open GOST (SIL OFL 1.1, in `src/lib/assets/fonts`), the rest through Fontsource.

All audio is synthesized in the browser by `src/lib/ui/sound.ts`, with no sound files.

Weapon effects use published fits: Brode's overpressure fit, Miller's fallout scaling system, and thermal and radiation figures from Glasstone & Dolan and OTA 1979. It's a game model, not a hydrocode. [docs/EFFECTS.md](docs/EFFECTS.md) gives methods, sources, and how far the model sits from each published figure.
